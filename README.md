# Lynch Strategy Quant Backtest

该示例项目演示如何将彼得·林奇（Peter Lynch）的经典投资理念转化为可执行的量化筛选条件，并对 2020-2024 年间的美股与 A 股进行示例化回测。由于环境无法联网，项目使用在 `data/` 目录中准备好的年度快照数据来模拟这些市场中部分代表性公司的表现。

## 目录结构

- `lynch_strategy/`：核心 Python 模块，包含策略定义、数据加载与回测逻辑。
- `data/`：示例化的基本面与价格数据。
- `README.md`：项目说明。

## 快速开始

```bash
python -m lynch_strategy.main
```

脚本会输出美股（US）与 A 股（CN）在 2020-01-02 至 2024-12-31 期间，以 100 万初始资金、等权持仓的回测结果，包括筛选出的股票列表、最终净值、总收益率与年化收益率。

## 策略量化条件

结合林奇的投资偏好，示例中的基础筛选条件包括：

- PEG 小于等于 1.5，代表成长性与估值的平衡。
- 负债权益比（Debt/Equity）不超过 0.5，强调稳健的财务结构。
- 市盈率处于 5 至 35 区间，避免过高估值或潜在的价值陷阱。
- 营收与每股盈利（EPS）增速分别不少于 8% 与 10%。
- 流动比率不低于 1.2，保障短期偿债能力。
- 毛利率不低于 25%，确保业务具备较高的盈利质量。

这些阈值可以通过 `LynchCriteria` 数据类自定义。

## 限制与注意事项

- 由于无法实时获取行情与财报数据，`data/` 中的示例仅用于演示如何搭建量化流程，并不代表真实的投资建议。
- 数据粒度为年度快照，未考虑股息、换手成本等因素。
- 如果在可联网的环境运行，可替换数据加载逻辑，直接对接金融数据接口（如 yfinance、akshare 等）。
